One-time setup: install the Ad Snob helper

The website searches Meta through a small Chrome add-on, so searches come from your own browser (Meta blocks searches from servers).

  1. Get the extension folder from your team (or the ad-snob repo).
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and choose the extension folder.
  4. Reload this page.
