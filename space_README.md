# Creative Lens

The team's shared library of design-led Meta ads, sorted by design quality.
Ads are collected and scored by the Creative Lens Collector app on teammates'
laptops and stored in Supabase; this page shows them. Published by
`deploy_space.py` from the team's `creative-lens` repository.
