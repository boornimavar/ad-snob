# Creative Lens

The team's shared library of design-led Meta ads, sorted by design quality.
Ads are collected by the Creative Lens Collector app on teammates' laptops
and analyzed here. Uploaded by `deploy_space.py`; the source lives in the
team's `creative-lens` repository.
